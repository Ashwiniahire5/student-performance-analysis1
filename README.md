# Student Performance Analysis

## Project Overview
This project analyzes student performance using Python and Pandas.

## Objectives
- Analyze student marks
- Calculate average marks
- Identify the top-performing student
- Visualize student performance using a bar chart

## Technologies Used
- Python
- Pandas
- Matplotlib

## Dataset
The dataset contains student names and their marks in:
- Mathematics
- Science
- English

## Analysis Performed
1. Loaded the student dataset
2. Calculated average marks
3. Identified the top-performing student
4. Created a bar chart for average performance

## Conclusion
This project demonstrates basic data analysis and visualization
using Python, Pandas, and Matplotlib.
